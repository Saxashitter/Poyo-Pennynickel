#

Poyo Pennynickel is a character mod for SRB2 that aims to be difficult to play, but very rewarding. **This character originates from my upcoming game, [UNSTOPPABLE: Refill Mart](https://saxashitter.itch.io/unstoppable-prototype)**


## Features
- A full story, with cutscenes, music replacements, harder bosses, and dialogue. **(UPCOMING)**
- Support for multiple gametypes, such as **BattleMod**, **Murder Mystery**, **Zombie Escape 2** and more. **(UPCOMING)**
- Emotes!!
- Super duper awesome gameplay that will leave you questioning my design choices.
